# Lifetime Supply desktop

Official desktop installers for Lifetime Supply members. This repository distributes binaries only; portal source and member data are not included.

- [Download for Mac — Apple Silicon and Intel](https://github.com/prodbyelaye-droid/lifetime-supply-desktop/releases/latest/download/Lifetime-Supply-mac.dmg)
- [Download for Windows — 64-bit](https://github.com/prodbyelaye-droid/lifetime-supply-desktop/releases/latest/download/Lifetime-Supply-windows.exe)

Open the installer, then launch **Lifetime Supply**. Internet access and an active membership are required. Sign in using the code from your email; email links open your browser. Closing the app, signing out or going offline clears the app session.

**v1.0.0 is unsigned and not notarized.** macOS and Windows may show security warnings or block opening. Do not disable security protections. The portal integration is awaiting its coordinated release.
